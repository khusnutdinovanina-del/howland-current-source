# Генератор тока Howland

Проект печатной платы генератора тока на основе схемы Howland на 3-х ОУ OPA2277.

## Состав проекта

- Схема электрическая принципиальная (ГОСТ 2.759-82)
- Печатная плата (2 слоя)
- Библиотека компонентов по ГОСТ (git submodule)
- Gerber файлы для производства

## Компоненты

| Обозначение | Номинал | Партномер |
|---|---|---|
| DA1, DA2 | OPA2277 | OPA2277PA |
| R1, R3, R4, R5, R6, R8 | 10 кОм | RN55D1002FB14 |
| R7 | 125 Ом | RN55D1250FB14 |
| R9 | 9.87 кОм | RN55D9871FB14 |
| J1, J2, J3 | Разъём 2 пина | — |

## Генерация файлов
run.bat

Генерирует PDF схемы, BOM, Gerber файлы и отчёт DRC в папку output\.

## Технологические нормы

Плата изготавливается по нормам завода Резонит:
- Минимальная ширина дорожки: 0.25 мм
- Минимальный зазор: 0.25 мм
- Минимальный диаметр сверла: 0.3 мм
