# Генератор тока Howland на трёх ОУ

Проект печатной платы в KiCad. Схема генератора тока Howland на трёх
операционных усилителях (корпуса OPA2277, DIP-8).

## Состав проекта

| Что | Где |
|---|---|
| Схема электрическая принципиальная | `howland-current-source.kicad_sch` |
| Печатная плата (2 слоя) | `howland-current-source.kicad_pcb` |
| Библиотека УГО и посадочных мест | сабмодуль `lib` |
| Скрипт проверок и генерации | `run.bat` |
| Результаты (PDF, BOM, Gerber, DRC) | `output/` |

## Как клонировать

Библиотека лежит в отдельном репозитории
[howland-kicad-lib](https://github.com/khusnutdinovanina-del/howland-kicad-lib)
и подключена как git-сабмодуль в папку `lib`. Клонировать нужно так:

```
git clone --recurse-submodules https://github.com/khusnutdinovanina-del/howland-current-source.git
```

Если репозиторий уже склонирован без сабмодуля:

```
git submodule update --init
```

Пути к библиотекам относительные: `${KIPRJMOD}/lib/...`

## Библиотека

В `lib` лежат:
- `howland_gost.kicad_sym`: символ ОУ по ГОСТ 2.759-82;
- `howland_gost_footprints.pretty`: посадочное место `OPA2277_DIP8`.

## Схема

- Рамка и основная надпись по ГОСТ.
- Составной компонент обозначен через точку: DA1.1, DA1.2, DA2.1, DA2.2.
- Классы цепей: `Power` (+12V, -12V, GND), `Signal`, `Default`.
- В полях компонентов заполнено `Manufacturer_Part_Number`.

## Компоненты

Заполни по файлу `output/bom.csv`, чтобы обозначения совпадали со схемой.

| Обозначение | Номинал | Manufacturer_Part_Number |
|---|---|---|
| DA1, DA2 | OPA2277 | OPA2277PA |
| R1, R3, R4, R5, R6, R8 | 10 кОм | RN55D1002FB14 |
| R7 | 125 Ом | RN55D1250FB14 |
| R9 | 9,87 кОм | RN55D9871FB14 |
| J1, J2, J3 | разъём 1x02, шаг 2,54 мм | — |

## Печатная плата

Нормы завода Резонит:
- минимальная ширина дорожки 0,25 мм;
- минимальный зазор 0,25 мм;
- минимальный диаметр сверла 0,3 мм;
- зазор до края платы 0,5 мм.

Дорожки проложены под углом 45°, цепь GND выполнена полигоном
на обоих слоях.

## Проверки и генерация файлов

Запуск: `run.bat`. Скрипт выполняет ERC, DRC, формирует Gerber-файлы,
перечень элементов (BOM) и PDF схемы. Результаты лежат в `output/`.
